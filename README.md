# CodSoft Web Development Internship - Task 2

## Responsive Landing Page

This project is a modern and responsive landing page created as Task 2 of the CodSoft Web Development Internship.

The landing page was developed using HTML and CSS with a focus on clean design, responsive layouts, and an improved user experience across different devices.

- Clean and organized code structure
